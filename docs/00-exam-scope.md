CHAPTER 1 — REVISION OF CLASS IX SYLLABUS

Treat this as the Java/programming foundation required by the other
chapters and by Section A.

The exact detailed Chapter 1 syllabus is not available in the supplied
chapter PDFs, so do NOT invent a detailed chapter-wise scope for it.

However, the examination explicitly expects revision knowledge through:
- Java expressions
- Java statements
- conversions
- output prediction
- program logic
- iteration/loops
- conditional statements
- other Class IX Java foundations needed for the prescribed programs

--------------------------------------------------

Scope supported by the school notes:

- Primitive and reference / non-primitive data types
- Java primitive data types
- Composite / user-defined data types
- Introduction to Object-Oriented Programming concepts
- Class
- Object
- Class as a blueprint/prototype
- Object as an instance of a class
- State of an object
- Behaviour of an object
- Data members / instance variables
- Member functions / member methods
- Defining a class
- Creating objects

The chapter continues with additional prescribed String methods;

Programming application includes:

- traversing strings
- testing characters
- manipulating case
- comparing strings
- extracting/manipulating portions of strings
- constructing transformed strings
- solving String-based logic problems

IMPORTANT EXAM APPLICATION:
A complete program using String methods is explicitly part of
Section B.

number/iteration logic such as:

- number series
- Fibonacci series
- Pronic number

- EvenPal
- Armstrong number
- minimum and maximum digit
- digit extraction and processing
- sums/products/counts of selected digits

Therefore NUMBER-BASED LOGIC MUST be treated as part of the exam
preparation scope.
