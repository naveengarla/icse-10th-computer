# School material (transcribed)

These are Markdown transcriptions of the school-provided PDFs. **They are the authority for the depth and style of exam answers** (see the scope rules in [../01-problem-statement.md](../01-problem-statement.md)). Use them instead of the original PDFs, which are not in the repo.

## Rules for these files

- **The text is reproduced as printed.** The school's typos and code bugs are kept on purpose, so don't "fix" them here. If you reuse one in portal content, fix it there, and make sure the engine and the `--jdk` tests agree.
- **Identifying details have been removed:** school name, logo, address, and teacher and student names. Do not add them back.
- **Handwritten student answers are left out.** A few teacher corrections to question text are kept and labelled.
- Some names appear only as sample data inside programs (for example "Abhishek" and "Sanjay Kumar"). These are part of the teaching examples.
