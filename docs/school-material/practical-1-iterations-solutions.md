## Program 1: Sum of series i/(1+a)^i

1. Define a class to find and display the sum of the given series:

    sum = 1/(1 + a)^1 + 2/(1 + a)^2 + ……………………. n terms

Where a and n has to be input by the user.

### Solution

```java
import java.util.*;

public class p1

{

    void main()

    {

        Scanner sc=new Scanner(System.in);

        System.out.println("Enter number of terms");

        int n=sc.nextInt();/**no of terms*/

        System.out.println("Enter value for a");

        int a=sc.nextInt();/**no of terms*/

        double sum=0;/**sum of series*/

        for(int i=1;i<=n;i++)/**i is looping variable*/

        {

            sum=sum+i/Math.pow(1+a,i);

        }

        System.out.println("The sum of series is = "+sum);

    }

}
```

## Program 3: Fibonacci series

3. Define a class to display the following Fibonacci series upto n terms. The first two terms of the series are 0 and 1, the next term is generated by adding the previous two terms.

    0, 1, 1, 2, 3, 5, ……………..n terms.

### Solution

```java
import java.util.*;

public class p3

{

    void main()

    {

        Scanner sc=new Scanner(System.in);

        System.out.println("Enter the number of terms");

        int n=sc.nextInt();/**number of terms*/

        int f=0,s=1,sum=0;/**f-1st tersm, s-2nd term*/

        System.out.print(f+" "+s+" ");/**print first and second term*/

        for(int i=1;i<=n-2;i++){

            sum=f+s;/** to get the next term add f and s*/

            System.out.print(sum+" ");

            f=s;/**now second term become the 1st term*/

            s=sum;/**now sum become the 2nd term*/

        }

    }

}
```

## Program 5: Pronic number

5. Define a class to accept a number and check whether it is a pronic number or not. A pronic number (also called an oblong or heteromecic number) is a number that is the product of two consecutive integers, expressed as n x (n+1)

For example:
6 is a pronic number because 2 x 3 = 6

### Solution

```java
import java.util.*;

public class p5

{

    void main()

    {

        Scanner sc=new Scanner(System.in);

        System.out.println("Enter a number");

        int n=sc.nextInt();/**Stores a number*/

        boolean found=false;/**flag variable*/

        for(int i=1;i<=n;i++)/**i is counter variable*/

        {

            if(i*(i+1)==n)

            {

                found=true;

                break;

            }

        }

        if(found==true)

        System.out.println("Pronic number");

        else

        System.out.println("Not a Pronic Number");

    }

}
```

## Program 6: EvenPal number

6. Define a class to accept a number and check whether it is EvenPal Number or not. A number is called EvenPal if the reverse of the input number is same as original number and sum of its digits is an even number.

Example: Input number: 121
Output: EvenPal [ reverse of 121 is 121 and sum of its digits 1+2+1 is 4 [even]

### Solution

```java
import java.util.*;

public class p6

{

    void main()

    {

        int n,r,rev=0,sum=0;

        Scanner sc=new Scanner(System.in);

        System.out.println("Enter a number");

        n=sc.nextInt();/**take input for a number*/

        int num=n;/**copy of n*/

        while(n>0)

        {

            r=n%10;/** fetch a remainder*/

            rev=(rev*10)+r;/** reverse the number*/

            sum=sum+r;

            n=n/10;

        }

        if(num==rev && sum%2==0)

            System.out.println("Even Palindrome number  ");

        else

            System.out.println("not a Even Palindrome number  ");

    }

}
```

## Program 7: 3-digit Armstrong number

7. Define a class to accept a number and check whether it is a 3-digit Armstrong number or not. A number is called Armstrong if the sum of cubes of the digits of n equals the input number n.

Example: Input number: 153
Output: Armstrong number [ 1³+5³+3³ = 153]

### Solution

```java
import java.util.*;

public class p7

{

    void main()

    {

        int n,r,sum=0;

        Scanner sc=new Scanner(System.in);

        System.out.println("Enter a number");

        n=sc.nextInt();/**take input for a number*/

        int num=n;/**copy of n*/

        while(n>0)

        {

            r=n%10;/** fetch a remainder*/

            sum=sum+(int)Math.pow(r,3);

            /**calculate power of remainder and add it */

            n=n/10;

        }

        if(num==sum)

            System.out.println("Armstrong number  ");

        else

            System.out.println("not a Armstrong number  "+sum);

    }

}
```

## Program 8: Minimum and maximum digit

        Maximum digit is 8

## Program 9: Digit operations (first+last, divisible by 3, odd product, even count)

9. Define a class to input a number and find and display the following:-
1) sum of first and the last digits.
2) sum of digits that are divisible by 3.
3) product of ODD digits
4) count of digits that are EVEN.

### Solution

```java
{
    void main()
    {
        Scanner sc=new Scanner(System.in);
        System.out.println("Enter n value");

        int s1=0;/**sum of 1st and last digits*/
        int s2=0;/**sum of digits divisible by 3*/
        int p=1;/**product of odd digits*/
        int c=0;/** count of even digits*/
        last=n%10;
        while(n>0)
        {
            int d=n%10;
            first=d;
            if(d%3==0)
            s2+=d;
            if(d%2==1)
            p*=d;
            if(d%2==0)
            c++;
            n/=10;
        }
        s1=first+last;
        System.out.println("Sum of first and last digits="+s1);
        System.out.println("sum of digits divisible by 3="+s2);
        System.out.println("Product of odd digits="+p);
        System.out.println("Count of even digits="+c);
    }
}
```

## Program 10: Clarit number

10. Define a class to input an integer number and check and display whether it is a Clarit number or not. A number is called Clarit, if the number of zeros are more than any other digit in the number.

| Example1: | Example2: |
|---|---|
| Input Number: 2004 | Input Number: 204 |
| Output: Clarit number. | Output: Not a Clarit number |

### Solution

```java
import java.util.*;

class p10

{

    void main()

    {

        Scanner sc=new Scanner(System.in);

        System.out.println("Enter a number");

        int n=sc.nextInt();/**stores a number*/

        int c1=0;/**stores the count of 0's*/

        int c2=0;/**stores the count of other digits*/

        while(n>0)

        {

            int d=n%10;/**stores a digit*/

            if(d==0)

            c1++;

            else

            c2++;

            n=n/10;

        }

        if(c1>=c2)

        System.out.println("Clarit Number");

        else

        System.out.println("Not a Clarit Number");

    }

}
```
