  1. Read and predict the output.
  2. Reveal the expected output and compare.

  4. Finish the notebook task without copying.

How to run these examples

Click Copy runnable code, open W3Schools Java editor ↗, replace all its code with the copied program, and click Run. On a computer: click in the editor, Ctrl+A, Ctrl+V.

The displayed code is a complete runnable program. Its extra public class Main starts the school-style class. For the handwritten BlueJ exam, use the School / BlueJ version under each example; the web-editor launcher is not an extra exam topic.

Examples use fixed inputs so they run without keyboard-input setup. Change the arguments to experiment. Expected outputs below are calculated from the examples.

Practise on paper after running. Explain the output and reconstruct the program.
