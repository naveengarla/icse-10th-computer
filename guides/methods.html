Chapter 3 · Methods

Seven batches. Paper first.

ICSE Class 10 · Methods · Q1 / Q2 → Q4

Learn methods by doing

Predict on paper. Check. Change one thing. Try again.

27 short tasks in seven batches. Start with calls; finish by writing your own methods. About 50 minutes for the core path; W3Schools experiments are optional.

Your answer sheet comes first
  1. Attempt each question in your notebook, or type your prediction.
  2. Reveal the computed answer and the brief reason.
  3. If needed, use W3Schools to verify or explore a variation.
  4. Finish the two notebook tasks without a computer or visible solution.
Using W3Schools

Open the optional check under an exercise, copy the runnable code, replace all code in W3Schools, and Run. The displayed exercise uses school / BlueJ structure; the copied version adds a launcher for the web editor.

Practise on paper after running. Explain the output and reconstruct the program.
